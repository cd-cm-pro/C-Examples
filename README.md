# C-Examples
This repository contains practical C code examples for learning, testing, and quick reference.

# Features
- Practical C examples for learning and quick reference
- Covers common topics such as arrays, strings, structs, pointers, math, files, threads, and networking
- Includes Windows-specific examples like window creation, message box, file dialog, process creation, COM, and keyboard input
- Provides utility examples for file I/O, string handling, type conversion, sorting, encryption, hashing, and compression
- Organized by topic so you can quickly find the example you need
- Simple run scripts for Windows and Linux

# Quick Run

Windows:
```bat
./run.bat <folder path> <compile option>
```

Linux:
```sh
./run.sh <folder path> <compile option>
```

Example:
```bat
./run.bat "Hello World"
```
